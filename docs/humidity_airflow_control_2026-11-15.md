# 湿度要求による発停・風量選定の修正（2026-11-15）

基準版は `93c9378`（PR #43）。修正コードは `65f2a72`、[PR #45](https://github.com/iguchi-lab/vtsimnx/pull/45)。

## 問題と修正

湿度優先のDUCT_CENTRALは、湿度要求で起動しても設計最大風量へ固定されていた。
顕熱負荷が小さい時刻では吹出温度が十分下がらず、室温の低下によってRHが高くなる一方、
必要な除湿ができなかった。顕熱負荷だけを使う通常の風量則や能力不足時の増風量も、
湿度要求に基づく候補を上書きする可能性があった。

- `CoolingRequest` に温度・除湿・再熱要求と過冷却制約をまとめ、発停と風量候補の生成に共用する。
- DUCT_CENTRALの湿度制御では有限個の風量候補を比較する。各候補の実風量は換気回路網で求め、
  熱・水分・能力・コイル下限・過冷却制限を解き直す。
- 前時刻の成立風量と室温を初期値にし、温湿度が達成できたら追加探索を打ち切る。
  発停はその時刻の要求で決め直す。前時刻の低風量と更新された高い設定温度をそのまま組み合わせない。
  初期値が使えない場合は最大風量で解き直す。
- 乾きコイルへの移行では古い固定湿度境界を解除し、混合未知数として解く。
- 飽和防止の安全余裕を持つ目標と、実際の過飽和判定を区別する。ACと吹出プレナムの状態を
  double・float32の両方でRH100％以下と検査し、許容内の目標変動だけでは再反復しない。
- 室から逆流する空気が混合する出口も検査する。混合後に過飽和となる試算は、
  プレナム凝縮・凝縮熱をモデル化していないため採用しない。水分だけを削除する処理はしない。

温度優先・暖房の負荷追従風量は既存の制御を使う。除湿側のコイル温度はCOPモデルへ渡さず、
受理された顕熱・潜熱処理量と実風量を使用する。

## 選定と失敗の区別

初期点と顕潜熱要求から求めた候補が温湿度を満たせない場合、既存の制御最低風量比から
最大まで5点に探索を広げ、温湿度を満たす点が得られたら打ち切る。全点が未達なら
温度の上側未達、湿度未達の順に選び、同程度なら先に成立した点を保つ。
電力は順位付けに使わず、運転状態から結果として計算する。温度・RHの許容帯は0.1 K・0.1ポイント。
過冷却下限や物理収支の許容誤差を緩めるものではない。

数値的に温度領域を外れた試算や内側連成の反復上限に達した試算は、理由を記録して除外する。
これは物理的実現不能の証明ではない。直前の成立状態に戻し、全候補で同じ時刻開始蓄積量を使う。
最大風量での初期点・選定点の失敗、個別の圧力・熱・湿気ソルバの未収束、非有限温度はエラーのまま扱う。
選定点の再求解・共通受理検査が終わるまで、蓄積量の時間更新や出力は行わない。

候補切替は最大 `8 × 空調台数` 回。各候補には既存の制御反復上限を適用する。
有限候補による制御であり、毎時の電力最小化や全時刻のRH達成を保証するものではない。
詳しい仕様は[室温・室湿度の制御モード](aircon_room_humidity_modes.md)に記載する。

## 検証条件

対象は「sim検討2／隙間比較_003」由来のC=4.74 cm²/m²の住宅モデル。
全館空調1台がLDを制御する条件であり、[標準住宅の基本ケース（AC4台）](vs_simheat_example.md)とは区別する。
設定は保存済み入力から変更せず、冷房時LD 27℃・RH60％、過冷却幅2 K、コイル下限5℃、再熱なし。
RH95、BF固定0.1、BF風量補正（基準風量で0.1）、Ao/Af、理想飽和コイルの5方式を比較する。

年間入力は比較元とバイト単位で同一であり、各条件の入力ハッシュを検証記録に保存する。
最終ソルバSHA256は `2cc7d432b23c5116b1c25a1a1cd6755b48924af67ccd654d2725a15bbc17015d`。

- Python engine 572件合格、性能試験1件除外。C++ 29件合格。
- [コード65f2a72のGitHub CI](https://github.com/iguchi-lab/vtsimnx/actions/runs/43699088238)は15ジョブすべて合格。
  Python 3.10〜3.13、物理回帰、ASan/UBSanを含む。
- PQファンでの湿度のみの起動・停止・再起動、5潜熱方式、実風量、水分収支、コイル下限を検査。
- 天候・設定値・OFF指定が変わる場合、以前の風量が新しい要求を上書きしないことを5方式で検査。
- 逆流混合の過飽和、候補復帰時の制御状態、送風確認から除湿への段階遷移をC++回帰に追加。
- BFの93時間目で起きた安全余裕目標への追従停滞は、修正後の住宅120時間再計算で解消。
- 出力された時系列から室・材料の水分収支とコイルの前進計算を独立に再構成する。

## 同一入力の短期再現

8月4〜10日の168時間で比較した。初期温度・湿度・圧力には保存済みの前時刻出力を与え、
修正前後の入力は同一。応答係数の隠れた履歴は復元しておらず、年間計算の完全な再開点ではない。

| 方式 | 途中版 b30cd47 [秒] | 修正版 2cc7d43 [秒] | 短縮率 | 修正版のAC出口最大RH [%] |
|---|---:|---:|---:|---:|
| 理想飽和コイル | 394.58 | 163.72 | 58.5% | 99.999994 |
| BF風量補正 | 405.70 | 170.75 | 57.9% | 99.999973 |

途中版は両条件とも出口RH100％超で不合格、修正版は両条件とも物理検査に合格。
各37節点×167時間の水分収支を出力から独立に再構成し、float32丸めの見積もりを超える欠損は0。
最大絶対残差は `8.33e-10 kg/s` 以下。コイル下限5℃、実風量との顕潜熱整合、電力も確認した。
上表の時間は2 vCPUサーバーで各版2条件を同時実行した値であり、年間の倍率とは別である。

短期再現では、送風確認の温度探索が停止幅に入り、除湿要求が残ったまま中間状態を受理する境界も
特定した。除湿段階への遷移を必須にし、候補を戻す際の制御状態も揃えて再検証した。

## 年間5方式の最終結果

5方式すべて8760時間、合計43,800時間で共通受理検査と出力の独立物理検査に合格した。
以下は同一入力による基準版 → 修正版の比較。湿度・電力量は冷房指定期間の2808時間を集計する。
年間の数値検証合格は、毎時RH60％を達成したという意味ではない。

| 方式 | LD平均RH [%] | RH60.1％超 [時間] | 冷房電力量 [kWh] |
|---|---:|---:|---:|
| RH95 | 71.30 → 59.22 | 2,347 → 1,117 | 1,369.6 → 1,772.5 |
| BF固定0.1 | 71.70 → 60.28 | 2,359 → 1,162 | 1,371.4 → 1,607.1 |
| BF風量補正 | 71.31 → 59.84 | 2,327 → 1,153 | 1,371.0 → 1,801.1 |
| Ao/Af | 68.70 → 59.93 | 2,032 → 1,096 | 1,314.1 → 1,566.4 |
| 理想飽和コイル | 72.98 → 59.72 | 2,420 → 1,154 | 1,358.1 → 1,809.4 |

理想方式でもRH最大は91.48％であり、未達は残る。未達1,154時間のうち1,028時間は室温25.001℃以下だった。
運転時の過冷却下限25℃やコイル下限5℃を維持した条件として記録するが、
有限個の風量候補しか試していないため、すべての未達が物理的に不可避とは断定しない。
冷房電力量は増えている。除湿処理の追加を含む比較であり、省エネ効果として扱わない。

| 方式 | 年間計算時間 [分] | 連成反復数 [回] | 修正版の混合出口最大RH [%] |
|---|---:|---:|---:|
| RH95 | 15.36 → 29.36 | 147,635 → 280,379 | 96.227280004 |
| BF固定0.1 | 16.19 → 22.30 | 155,683 → 332,183 | 99.999997197 |
| BF風量補正 | 16.40 → 32.05 | 156,576 → 302,706 | 99.999999703 |
| Ao/Af | 15.71 → 33.43 | 154,579 → 319,139 | 99.999983092 |
| 理想飽和コイル | 9.31 → 29.03 | 153,757 → 297,588 | 99.999999258 |

計算時間は同じ2 vCPUサーバーで測定。最大2条件を並列実行し、終了順によって同時負荷は変わる。
電力による順位付けを廃止し、初期値の再利用・達成時の打切りで途中版より短縮したが、
風量候補ごとの連成再計算により、元の基準版よりは時間がかかる。

出力された37節点の水分収支を、初期蓄積量が未出力の先頭1時間を除いて独立に再構成した。
検査数は合計1,620,415節点・時間、最大絶対残差は`9.278603e-10 kg/s`、float32丸め見積もりを除いた最大正規化残差は`0.000000e+00 kg/kg`。
コイル前進計算による出口絶対湿度の最大差は`1.004755e-07 kg/kg`。
内部の出口境界許容値は`1e-7 kg/kg`のまま。独立前進計算では、出力された温度・湿度・風量の
float32丸めの伝播分`5e-9 kg/kg`を加えた`1.05e-7 kg/kg`を検査限界とする。
既存の受理許容値を緩めずに、実回路網の風量、顕潜熱、電力、出口RHを検査した。
