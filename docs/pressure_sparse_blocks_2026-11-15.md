# 圧力計算の接続関係に沿った行列化（2026-11-15）

比較基準: main `95af952d1670e5c3b70142b755740fa892f9f71b`。
対象: [Issue #35](https://github.com/iguchi-lab/vtsimnx/issues/35) の圧力ソルバー構造改善。
実測値・入力と実行ファイルのSHA-256は [検証JSON](validation/pressure_sparse_blocks_2026-11-15.json) に保存する。

## 変更

従来は、1室の流量収支を全室の圧力を含む1つのパラメータブロックとしてCeresに渡していた。
疎行列の解法を選んでも、ブロックの内部は密な行列となる。
今回は各収支に関係する未知圧力だけを1変数ずつ登録し、境界枝・局所添字を問題作成時に確定する。
固定流量・無効枝は圧力の未知変数を増やさない。固定流量だけの不釣合いも定数残差として残し、物理収支で不合格にする。

通常計算・集約するStage A・復元するStage Bの全てで同じ評価実装を使用する。
ゲージアンカーも1変数だけに接続し、同じ圧力を共有する集約節点はパラメータを重複登録しない。
グラフの接続・有効/無効・固定流量の区分は各圧力求解の間は一定とし、次の求解では問題を作り直す。

未知圧力が64以上の標準LM試行と勾配精密化試行では、利用可能なら
`SPARSE_NORMAL_CHOLESKY` を使用する（SuiteSparse、次いでEigen）。小規模系は `DENSE_QR`。
疎行列バックエンドがないビルドではQRを使う。堅牢試行のDOGLEG + QRも維持する。
正規方程式による解法には条件数の悪化があるため、解法選択だけで成功とはせず、従来どおり節点ごとの物理収支で採否を決める。
風量式、小差圧線形化、ファン特性、物理許容誤差、勾配精密化の条件、フォールバックの成功判定は変更していない。

参考: Ceres公式の [パラメータブロックと微分](https://ceres-solver.readthedocs.io/latest/nnls_modeling.html)、
[線形ソルバーの選択](https://ceres-solver.readthedocs.io/latest/nnls_solving.html)。

## 検証結果

- C++: **29件合格**。解析微分と中央差分、固定圧境界、並列枝、固定流量、無効枝、集約節点、部分的なnull Jacobian、定数残差を確認。
- 17 / 64 / 256節点の鎖状回路で、CeresのJacobian格納要素が `N²` ではなく `3N−2` となることを検査。
- engine Python: **553件合格**（perf 1件を除外）。64節点の弱い隙間 `a=1e-8`、許容 `1e-12 m³/s` の既知解を追加。従来の弱勾配・圧力収支・連成安全性の回帰も含む。

### 圧力のみの既知解ベンチマーク

2 vCPUの同じLinuxサーバーで、48時間・各3回の圧力計算時間の中央値を比較した。
外気と各室・隣室間に平方根則の隙間を置き、時変の既知圧力から独立に固定排気量を作る。
これは **人工回路網** であり、標準住宅やIssue #33の元入力ではない。

| 未知圧力数 | 旧版 [ms] | 改良版 [ms] | 旧版時間 / 改良版時間 |
|---:|---:|---:|---:|
| 17 | 16.89 | 17.20 | 0.98（ほぼ同等、約1.8%増） |
| 64 | 206.62 | 88.10 | 2.35 |
| 128 | 1011.23 | 162.15 | 6.24 |
| 256 | 6982.60 | 316.16 | 22.09 |

全試行が完走し、フォールバック0回。反復数は旧版と同じ。
既知圧力に対する最大差は `7.55e-6 Pa` 以下、float32出力から独立に再計算した
体積流量収支は `9.49e-9 m³/s` 以下（solverの設定許容は `1e-8`）。
各規模の1回目の全float32系列は旧版と完全一致した。
高速化の倍率はこの疎な回路網・環境での測定値であり、全ての住宅・密な回路網での倍率を保証しない。

```bash
python3 engine/tools/benchmark_pressure.py \
  --solver engine/build/vtsimnx_solver --output /tmp/pressure-benchmark
```

### 標準住宅の基本ケース（AC4台）

[`standard_house_ac4`](vs_simheat_example.md) はLD・寝室・子供室1・子供室2に各1台を設置した基本ケース。
旧版・改良版とも **8760時間を完走**。室温・換気量・AC顕熱の全出力差はゼロ、外側反復は双方10858回。
この基本入力は固定流量のみで圧力求解0回であり、この年間比較は基本ケースへの影響確認である。
圧力計算の速度・精度の根拠は上記の既知解ベンチマークと回帰テストによる。

## 残っている確認

[Issue #33](https://github.com/iguchi-lab/vtsimnx/issues/33) の元入力は、基本ケースに窓・建具の隙間を追加したもの。
元の隙間係数・高さ・接続を特定できていないため、同じ住宅入力での
倍率0.1 / 0.01 / 0.001・1月744時間の再実行は **未実施**。
本変更をIssue #33の元入力再現完了とは扱わず、Issueも閉じない。
小差圧しきい値とファン平滑化の見直し、フォールバック全体の再設計は別途検討する。
