# v1.7.3

v1.7.2以降のログ・回帰テスト修正、サンプルデータの扱いの変更、および技術文書の改訂をまとめるパッチリリースである。

## 主な変更

- solverのログに分野別タグと重大度ラベルを統一して付与した。
- 物理回帰テストでログの `[INFO]` を無限大の `Inf` と誤判定する問題を修正した。
- サンプル気象データ `examples/3639999.has` の同梱を廃止し、SimHeat比較例を外部ファイル指定へ変更した（#4）。
- `docs/` を実装と照合し、単位・符号・入力例・数値解法・適用限界を修正した（#5）。
- 応答係数法の独立ガイドと技術文書v3.2の6.7節を追加した。係数生成元のRCモデル、後退Euler離散化、次数削減、履歴初期化、出力の定義を説明した。
- 技術文書v3.2のDOCX/PDFを同期し、PDF全51ページを確認した。v3.2は文書の版番号であり、パッケージの版番号v1.7.3とは別である。

## 確認結果

- 文書更新PR #5のCI（run 34016601796）は全12ジョブ成功。Python 3.10/3.11/3.13のクライアント・builderテスト、C++ CTest、物理回帰、wheelビルド・インポート、最小実行例、lint/typecheckを含む。性能履歴ジョブはwarn-onlyである。
- 文書の入力例をbuilderで展開し、単位換算と日射等を数値確認した。
- 全次数応答係数と生成元RCモデルを120ステップで照合し、熱流密度の最大差は1.8×10⁻¹³ W/m²未満であった。同じ離散モデル間の比較であり、実測や連続壁の解析解に対する精度保証ではない。

## 利用時の注意

- SimHeat比較例では、利用可能な気象データを別途準備し、外部ファイルとして指定する必要がある。
- 応答係数の次数削減時の定常熱収支、共通出力 `heat_rate` の定義、定常化・初期化など、点検で判明した実装上の課題は今回修正していない。
- 風圧係数、夜間放射、湿気容量、濃度更新等の制約も含め、詳細は[文書点検記録](../documentation_review_2026-09.md)と[応答係数ガイド](../response_factor_method.md)を参照する。
- 今回の文書点検は実装との整合を確認したものであり、すべての計算条件に対する物理的妥当性を保証するものではない。
