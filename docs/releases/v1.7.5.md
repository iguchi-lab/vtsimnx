# v1.7.5

v1.7.4 以降の全館空調の風量・ON/OFF と、計算待ち時間の調整をまとめるパッチリリースである。

## 主な変更

- 全館空調の還気と吹出を同じ循環風量に揃えた。`in == out` のループでも吹出を逆符号にしない。
- 設定を保持できているときの風量基準を、計測コイル熱ではなく室負荷 `|required_heat_w|` にした。能力制限中・要求未達は能力上限、室温が自由なときだけ計測処理熱を使う。
- 設定維持中に室負荷が `Q.min` 未満なら、機種を問わず停止する。停止すると再起動幅（最低 1 K）の外に出るときは、ON のまま最低能力を処理する。
- 全館空調は、固定風量のままか、`p_max`・`p1`・`q1`・`q_max` が揃ったときだけファン PQ の速度比で風量を決める。同じ枝に両方は載せない。
- ON/OFF 判定と風量の基準熱量選択を、コントローラから `aircon_onoff` と `aircon_airflow` に分けた。挙動とログ文言は変えていない。
- `run_calc` の既定待ち時間を 10 分にした。
- FastAPI 起動前に API キー用の環境変数を読むようにした。
- 上記に合わせて `engine/docs` の空調制御の考え方と手順を更新した。技術文書 DOCX/PDF への反映は後続改訂で行う。

## 確認結果

- Python: builder の `test_aircon.py`

## 利用時の注意

- 固定風量のとき、空調機ノードの圧力は未知数にしない。表示は初期値 0 のままで、室や吹出の圧力計算には使わない。
- ファン PQ にするときは、空調機ノードを圧力の未知数にする必要がある。今回の固定風量の既定は変えていない。
- 技術文書 DOCX/PDF（v3.2）への今回の実装反映は未実施。当面の正本は `engine/docs/` を参照する。
