# v1.10.0 — 住宅の外皮性能と等級別モデル

標準住宅の等級4～7について、床断熱・基礎断熱モデルの入力から外皮平均熱貫流率（UA）、冷房期・暖房期の平均日射熱取得率（ηAC・ηAH）と部位別の内訳を計算できます。窓の枠込み日射熱取得率や土間外周の長さ・線熱貫流率は設計条件として指定します。[外皮性能の計算方法](https://github.com/iguchi-lab/vtsimnx/blob/v1.10.0/docs/envelope_rating.md)

- Pythonからは `vt.envelope_performance(input_data, assessment)` を使用します。[計算用Colab](https://colab.research.google.com/github/iguchi-lab/vtsimnx/blob/v1.10.0/tutorials/standard_house_envelope_rating.ipynb)
- 基礎断熱モデルには外皮隙間の倍率を変更できる換気回路を追加しました。[隙間換気の比較用Colab](https://colab.research.google.com/github/iguchi-lab/vtsimnx/blob/v1.10.0/tutorials/standard_house_foundation.ipynb)
- v1.9.0以降の標準年気象の助走、庇付き窓の日射計算、人体発熱（活動レベル2で106 W/人）の修正を含みます。旧版と計算結果を比較する際は使用版を記録してください。

GitHubからインストールする場合は次のコマンドで版を指定できます。

```bash
python -m pip install "git+https://github.com/iguchi-lab/vtsimnx.git@v1.10.0"
```
