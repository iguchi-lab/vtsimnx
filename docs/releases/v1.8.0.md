# v1.8.0

v1.7.5 以降の全熱交換換気の追加と、空調 COP・ダクトファン PQ の修正をまとめるマイナーリリースである。

## 主な変更

- 全熱交換換気（顕熱 / 全熱）を追加した。OA・SA・RA・EA を別ノードに接続でき、固定風量（`vol`）または給気・排気それぞれのファン PQ（`p_max`・`p1`・`q1`・`q_max`）で流量を与える。
- 顕熱交換は温度効率 `eta_t`、全熱交換は温度効率に加え湿度効率 `eta_x` を用いる。給気温度・絶対湿度は還気側との熱交換後に更新してから圧力・熱の連成に入る。
- 出力に `hrv_sensible_heat` / `hrv_latent_heat` [W] を追加した。入力仕様と使い方は `docs/heat_recovery_vent.md` を参照する。
- 空調の処理熱がほぼ 0 のとき、COP 推定失敗にせず電力 0・COP 0 として扱うようにした。
- ダクトファンを PQ 指定したとき、圧力未知数として解くようにした。
- 全館空調まわりの技術文書・記法の整理と、v1.7.5 向けガイドの同期を反映した。

## 確認結果

- C++: `vtsimnx_solver_cpp_test_hrv_controller`、連成ステップのビルド（HRV 追加後の thermal include 修正、および `simulation_coupled_step` を使うテストへの HRV リンク追加を含む）
- Python: builder の `test_heat_recovery_vent.py`
- wheel: `vtsimnx-1.8.0-py3-none-any.whl`

## 利用時の注意

- 全熱交換は `recovery: "sensible"` または `"total"`。顕熱のみのときは `eta_x` は 0 扱いになる。
- 給気・排気を別 PQ にする場合は `supply` / `exhaust` の両方を揃える。`vol` と同時に載せない。
- 短い入力（`outdoor` + `room`）では OA=EA=室外、SA=RA=室として接続する。
- 技術文書 DOCX/PDF（v3.2）への全熱交換の反映は未実施。当面の正本は `docs/heat_recovery_vent.md` と `engine/docs/` を参照する。
