# v1.8.1 — 領域別点検で確認した不具合の修正

2026-11-01。修正対象はv1.8.0/main `6288389`の点検で整理した8項目。

| 対象 | 修正後の挙動 |
|---|---|
| A-01 API認証 | 設定済みキーの全失効、空のキー配列、JSON設定不正でも認証を解除しない。未設定時のローカル動作と公開ヘルスチェックは維持 |
| C-01 HRV濃度 | HRV給気・排気を容量なしの内部未知数として同時に解く。同濃度400を維持 |
| H-01 水分移動量出力 | HRV・空調吹出等の固定境界も共通状態に同期して流束を出力 |
| T-01 応答係数の次数削減 | 省略モードの定常寄与を直接項に戻し、等温熱流ゼロ・定常U・相反性を保持 |
| C-02 多室濃度保存性 | 旧上流濃度で別々に積分する方式から、結合節点の有限体積連立陰解法へ変更。閉鎖系のΣV cを保存 |
| E-01 風圧 | 符号付き外圧係数に統一。既定の風下係数−0.55から負圧を返す |
| E-02 夜間放射 | 温湿度推算と直接入力を外向き損失正のW/m²に統一。表面への接続で冷却となる |
| I-01 計算設定 | simulation.coupling・iteration・旧形式の反復上限・logをAPI/直接builderで検証して引き継ぐ |
| 最終HTTP検査で追加確認 | heat_recovery_ventとそのbuilderオプションをAPIスキーマに登録。strict時の拒否、strip時の機器定義削除を解消 |

## 計算結果・入力の変更点

- 多室の濃度は後退Euler法（時間一次精度）。総量保存と過渡精度は別であり、刻み感度を確認する。他の未知節点と結合しない有限体積は、従来の局所解析解を保持する。
- 容量なし混合節点の除去率を混合分母で相殺しない。HRV内部の未知数は、公開のcalc_c系列を増やさずに扱う。
- 旧版の風圧符号を補うためc_outを正に変えていた入力は、負の外圧係数へ戻す。夜間放射の返り値を手動で反転していた入力は補正を外す。正値の放射損失を直接入力する経路は変更なし。
- coupling・iterationを以前からraw/APIに書いていた場合、今回から実際に有効になる。無効値や未知の設定は検証時に拒否または警告する。
- 明示したlog.verbosityは保持する。未指定時は従来の既定値、debugは指定レベル以上へ引き上げる。
- 履歴初期化・極端に遅い壁の定常化、PMV低代謝域、ガラスの未吸収日射などは今回の対象外。
