# v1.9.0 — 標準住宅の部品カタログ

2026-11-17。標準住宅を `vt.standard_house` から部品として選べるようにした。気象は組み込まない。

| 対象 | 挙動 |
|---|---|
| 標準住宅 | `import vtsimnx as vt` のあと `vt.standard_house`。気積・層・庇・部位・換気・空調を名前で取り出す |
| 換気・空調 | `ventilation["24h"]` と `aircon["ac4"]` はコピーを返す。枝や台数・機種をその場で差し替えてよい |
| 気象 | 外気温・日射・地盤温度は呼び出し側。`bind_surface_types` で用意済み系列を部位へ載せる |
| 組み立て例 | [`examples/vs_simheat_sample.py`](../../examples/vs_simheat_sample.py) |

experimental API の追加であり、既存の入力 JSON と engine の契約は変えていない。
1.8.1 の領域別修正は未タグのまま main に含まれ、この版に同梱する。
