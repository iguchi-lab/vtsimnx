# 圧力反復中の風量式の種別判定を共通化（2026-11-15）

比較基準: PR #40 / main `e551591bea6ab99c02c052db2d88ef9ab32fff82`。
対象: [Issue #35](https://github.com/iguchi-lab/vtsimnx/issues/35) の種別判定の列挙型化のうち、圧力残差と微分の最内側。

## 変更

`FlowLaw` を導入し、無効・固定体積流量・開口・隙間・ファン・圧損・未知の区分を共通化した。
各圧力問題を作る際に枝の有効状態・固定流量の上書き・種別から区分を決定する。
Ceresの反復中は、風量と解析微分が同じ列挙値を使い、文字列の比較を繰り返さない。
通常計算とStage A/Bは共通の残差実装を通るため、同じ規則になる。

入力パーサだけで種別を固定すると、フォールバックによる一時的な固定流量化や各時刻の無効化を取り違える可能性がある。
そのため、列挙値は変更可能な `EdgeProperties` に永続的にキャッシュせず、各圧力問題の寿命に限定する。
既存の2引数の風量・微分関数は、その時点の枝を毎回分類する。JSON入力や直接C++から枝を更新する呼び出し方は維持する。

無効化は固定流量より優先する。`type=fixed_flow`、明示した `vol`、旧C++の `vol` 系列のいずれも固定流量として扱う。
未知の種別の直接C++呼び出しは従来どおり風量0・微分0とする。入力パーサの未知種別の拒否規則は変更しない。
各風量式・解析微分・許容誤差・空調制御は変更していない。

## 検証

- C++ 29件合格。既存の開口・隙間・ファン・圧損の微分検査に加え、同じ枝を使った固定流量化→復元、有効→無効→有効、ファンへの変更、`vol` の上書きの回帰を追加。
- engine Python 553件合格（perf 1件を除外）。
- 人工回路網17/64/128/256変数、48時間、各3回で、既知解の精度と旧版との出力一致を確認。
- 標準住宅・基本ケース（AC4台）は旧版・改良版とも年間8760時間を完走。室温・換気量・AC顕熱の全出力差ゼロ。

人工回路網の圧力計算時間（各3回の中央値、同じ2 vCPU Linuxサーバー）:

| 未知圧力数 | PR #40 [ms] | 本変更 [ms] | 短縮率 |
|---:|---:|---:|---:|
| 17 | 17.567 | 15.223 | 13.3% |
| 64 | 88.095 | 75.768 | 14.0% |
| 128 | 162.472 | 140.320 | 13.6% |
| 256 | 313.267 | 261.853 | 16.4% |

この倍率は人工回路網での実測であり、住宅全体の計算時間の短縮率を示すものではない。
入力・実行ファイルのハッシュ、各回の測定値、出力比較は [検証JSON](validation/flow_dispatch_2026-11-15.json) を参照。
再実行には `engine/tools/benchmark_pressure.py` と `engine/tools/benchmark_standard_house.py` を使う。

## 残る範囲

空調の運転・制御モード、換気の前処理や熱側の種別判定を含む全面的な列挙型への移行は未完。
本変更の検証時点ではIssue #33の元の隙間追加住宅入力は未特定だった。
その後、利用者指定のノートから元入力と旧版の停止を再現し、連成側の残る問題を修正した。
[元入力の特定と追加修正](gap_house_replay_2026-11-15.md) を参照。本ページの人工回路網の測定とは区別する。
