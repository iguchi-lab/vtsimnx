# Ao/Af法の報告書式への復元（2026-11-16）

対象は `coil_aoaf` と別名 `aoaf` / `literature`。参照は「湿度を考慮した室内環境および省エネルギー性能評価委員会」報告書4.2.1、本文44–45ページ（PDF46–47ページ）の手順4)〜8)。コードは `62a6190`。

## 復元した仕様

- 伝達率を `0.037*ln(V/Af)+0.0637` に戻し、400 m³/h相当への風速置換を廃止した。
- 仮の出口状態と吸込状態の算術平均から、コイル表面温度と潜熱量を算定する。NTU接触効率への置換を廃止した。
- Ao/Afのコイル下限は復元した表面温度式で逆算する。BF法、COPモデルは変更しない。COPには除湿側のコイル温度を渡さない。
- 潜熱量は共通の潜熱換算値で水分除去量へ変換し、非負・非加湿・出口飽和制約と収支を適用する。

## 報告書との差として残す点

ユーザーの指定により、手順2)の前時刻値には戻さず、現在時刻の連成計算による吸込温湿度と実風量を使用する。

手順4)の `Xe=xsat(Te)` を厳密に用いた試作では、関連19試験のうちAo/Afの10試験が未収束となった。一例では、吸込絶対湿度7.959595 g/kg付近で潜熱量が0から約1269 Wへ飛ぶ。これは湿度許容誤差を緩めて解決する対象ではない。

承認された境界補正として `Xe=min(Xr,xsat(Te))` を用いる。仮の出口が吸込より湿る区間のみを補正する。完全に湿った領域では報告書式がそのまま残り、露点境界では潜熱が0へ連続的につながる。

報告書のlogの底は明記されていない。従前実装の自然対数を維持し、これだけでSimHeatとの完全一致は主張しない。算術平均モデルには、単一表面のBF混合恒等式や出口湿度がコイル飽和湿度を下回らない保証はない。詳細な式と適用範囲は[モデル説明](aircon_model_and_control.md#1045コイル面積法)を参照。

- 報告書の湿潤条件の独立参照値：吸込28℃・0.014 kg/kg、出口16℃、風量0.25 m³/s、Af=0.133 m²、Ao=4.84 m²、顕熱3621.6 Wに対し、コイル13.64984979℃、潜熱3132.64977 W。3つの方式名すべてで一致する。
- 乾湿境界・湿度による起動停止・設定変更・コイル下限の24試験が合格。
- 全Python engine試験572件合格（性能試験1件除外）、C++29件合格。
- C=4.74、全館空調1台、LD27℃・RH60％、湿度優先の8月4〜10日・168時間が正常終了。
- 出力された37節点×167時間の水分収支を独立再構成し、float32丸め見積もりを超える欠損は0。先頭時刻の初期蓄積量は未出力のため除外。
- ACと混合出口の最大RHは99.9999892％、推定コイル最低温度は5.02157℃。冷却負荷がある時刻では電力が正。
- コイル前進計算の出口湿度最大差は9.7931e-8 kg/kg。既存の境界許容値1e-7とfloat32伝播見積もり5e-9の範囲内。
