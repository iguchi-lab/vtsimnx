## 1. 適用範囲

本仕様書は、対象 commit の Python クライアント、Python ビルダー、HTTP サービス及び C++ ソルバの動作を記述する。既存文書と実装が異なる場合は、実装に合わせる。モデル上の近似、不便な挙動、入力経路による制限も省略しない。未実装の改善案を現行仕様に含めない。

文書の状態は本文初稿とする。読解で確認した処理と、実際に実行して確認した処理を区別する。後者の結果は[第十四章](14_validation.md)に記す。別途作成中の技術情報とは独立して管理する。

## 2. 構成要素及び用語

| 用語 | 定義 |
|---|---|
| raw JSON／raw_config | 面、機器、熱容量等を含む、ビルダーに渡す入力 |
| 計算用 JSON／solver_config | 展開・検証後に C++ ソルバへ渡す入力 |
| ノード | 温度、圧力、絶対湿度、濃度等の状態を保持する要素 |
| ブランチ | ノード間の流れ・熱伝達・湿気伝達又は発生量を表す要素 |
| 固定境界 | 当該物理量を未知数として解かず、入力値又は設備処理の値を用いるノード |
| 未知ノード | 当該物理量の収支式により値を求めるノード |
| タイムステップ | 時間刻み Δt に対応する計算単位 |
| 反復 | 同一タイムステップの連成・設備状態を整合させる計算 |
| 成果物 | schema、数値系列、manifest、ログ等の計算出力 |

固定境界は実行中に不変という意味ではない。空調機の吹出湿度や熱交換換気の給気状態は、設備処理によって更新される固定境界である。

## 3. 共通記号・単位

| 記号 | 意味 | 単位 |
|---|---|---|
| i, j, e | ノード、隣接ノード、ブランチ | — |
| n, k | 時間段階、同一時間段階の反復番号 | — |
| Δt | 時間刻み | s |
| T | 温度 | °C（温度差は K） |
| p | 回路網の圧力 | Pa |
| V | ノードの体積 | m³ |
| q | 体積流量 | m³/s |
| x | 乾き空気基準の絶対湿度 | kg/kg(DA) |
| c | 濃度 | 選択した物質量/m³ 等 |
| G | 熱コンダクタンス | W/K |
| C_T | 熱容量 | J/K |
| K_x | 湿気コンダクタンス | kg/s（湿度比差を乗じる） |
| C_x | 湿気容量（内部表現） | kg/(kg/kg) |
| Q, P | 熱流・処理熱量、電力 | W |
| E | 消費電力量 | kWh |

入力の風量は m³/s とする。m³/h の値は呼出側で 3600 で除す。ビルダーは自動換算しない。機器仕様 ac_spec の Q・P は kW を用いる項目があり、回路網の W と区別する。

濃度の単位は全体で一意に固定されていない。units.py は concentration_c を「-」、concentration_flux を kg/s と表記する一方、濃度実装は個/m³・個/s を想定したコメントを持つ。したがって出力の単位ラベルだけから物質量を確定しない。第十章で次元の対応を規定する。

## 4. 符号及び時間

換気流量は source → target を正とする。負の場合は実際の上流・下流を反転する。伝導枝の熱流は G(T_source−T_target) を基準とする。各出力の符号は第八・十一章も参照する。

時間配列の要素 n は当該ステップの境界・発生・設定条件に使用される。Python の時刻正規化で end は配列の最終ラベルとなる。初期状態の出力専用行が追加されると仮定しない。時間積分の旧値と、連成反復の直前値を区別する。

## 5. 仕様の適用経路

同じ名前の項目でも、raw JSON、計算用 JSON、HTTP 要求のそれぞれで受入条件が異なる。特に raw simulation の coupling・iteration は現在のビルダーで引き継がれない。C++ の対応機能がそのまま Python の run_calc から指定可能とは限らない（第三～五章）。
