## 1. 基準

仕様本文は対象 commit の実装を基準とする。既存文書との不一致は実装どおりの本文へ修正し、[付録](appendices.md)に対応を記録する。実装が物理的に理想的でない場合も、実際の処理を改善後の想定へ書き換えない。

## 2. 検証の区分

| 区分 | 内容 | 言えること |
|---|---|---|
| 実装読解 | 分岐、式、型、既定値の確認 | 対象ソースとの対応 |
| 実装呼出し | 実際の Python 関数と期待値の比較 | 実行した入力条件での一致 |
| 算術例 | 記載式を独立に評価 | 転記した例の算術的一致 |
| ソルバ検証 | C++ を実行し既知解・収支・回帰と比較 | 実行対象の数値特性 |
| 全体検証 | HTTP から成果物取得まで | 統合経路の成立 |

算術例の合格を C++ の合格と表示しない。

## 3. 今回用意した再現スクリプト

[examples/verify_examples.py](examples/verify_examples.py)を使用する。依存はプロジェクトの Python 依存ライブラリであり、pytest は使用しない。リポジトリのルートで次を実行する。

~~~text
python docs/specification/examples/verify_examples.py
~~~

出力は同ディレクトリの raw_example.json、solver_example.json、verification_results.json。既存のユーザー入力を使用せず、仕様書専用の最小例を生成する。各条件に assert を設け、失敗時に合格報告を残さないよう、報告ファイルは全確認完了後に書く。

## 5. 今後の詳細検証

換気は逆流・微小差圧・ファン接点・固定圧力・並列流路を検証する。熱は単一抵抗、単一容量、壁の定常・過渡、CTF履歴、放射係数と面積を検証する。湿気は双方向リンク・無容量・負値拒否・外側反復回数を変えた時間積分を検証する。濃度は発生・沈着・除去・無容量と多室の時間刻み依存を検証する。電力は零負荷、停止、例外、各機種の定格・部分負荷を分ける。

相対誤差・絶対誤差・収支残差の許容値は、物理量、保存精度、基準解に応じて定める。「テストファイルがある」だけでは仕様の全条件を検証済みとしない。
