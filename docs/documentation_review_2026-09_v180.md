## 4. 現行モデルの制約

- 熱交換換気は常時運転、交換効率一定の受動モデルであり、バイパス、着霜防止、ファン電力、効率の温湿度・風量依存は未実装である。
- 全熱交換の湿度効果を室へ反映するには、室側の湿気計算を有効にする必要がある。
- 回収熱量は給気・排気実風量の小さい方を有効風量として算定する。
- 給排気ファンPQでは、設定値そのものではなくファン曲線と流路抵抗の交点で実風量が決まる。
