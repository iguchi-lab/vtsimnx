## コード側に残る課題

今回の変更は文書であり、以下の挙動は実装修正していない。
文書に正しい挙動・制約を記載した上で、用途ごとの影響評価が必要である。

| 挙動 | 確認例・影響 | 関連文書 |
|---|---|---|
| 既定の風下風圧が正 | 東風2 m/sで東面+1.687 Pa、西面+1.326 Pa。係数符号の解釈を要確認 | [風圧等](archenv_comfort_nocturnal_wind_usage.md) |
| 温湿度推算の夜間放射が負になる | 5°C・70%で約−66.98。損失正のsurface入力への直結は加熱になる | 同上 |
| 低代謝時のPMV発汗項 | 1 met未満で負の発汗項を許し、規格適合性をそのまま主張できない | 同上 |
| 日射の受熱配分 | 配分先がない群や未吸収分の再配分・多重反射を追跡しない | [surfaces](surface_usage.md) |
| SimHeat例の水平面入力 | サンプル内にDNI+DHIの加算が残る。文書では正しい投影を示した | [比較例](vs_simheat_example.md) |
| raw湿気容量の結合 | 追加節点とのk=C/Δtが時間刻みで変わる | [単位](units.md) |
| 濃度の局所更新 | 上流旧濃度を固定。v<=0の混合では除去率が分母の重みにも作用 | v3.2第8章 |
| 応答係数の次数削減 | 上記2層例で1モードにすると定常行列は約[[0.76060, −0.81289], [−0.81289, 1.57574]] W/(m²·K)。行和が0でなく、等温時に非零熱流 | [応答係数](response_factor_method.md) |
| 応答係数の共通出力 | `heat_rate=(q_src+q_tgt)/2`。定常貫流の大きさを出力していない | 同上 |
| 応答係数の定常化・初期化 | 係数和の条件で蓄熱を除去。過去熱流0は温度差のある定常初期状態とは不整合 | 同上 |

今後の精度評価では、これらを確認した上で解析解・独立ソフト・実測と比較し、
境界条件、材料物性、時間・空間離散、予備計算、評価誤差指標を報告する。
