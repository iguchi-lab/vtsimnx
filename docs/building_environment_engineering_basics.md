# 建築環境工学の基礎（vtsimnx 向け）

本書は入力・出力を読むための物理量と基本仮定を説明する。一般的な保存則と現行実装の近似を区別し、APIの詳細は各機能ガイドを参照する。

## 1. 建物の熱収支

室の熱収支は「蓄積の時間変化＝正味流入熱＋内部発熱＋空調処理」と整理できる。日射、壁体伝熱、換気、放射、空調の寄与を同じ符号規約で加える。外気流入や外皮伝熱は、内外温度によって取得にも損失にもなる。

単純な一室の顕熱モデルでは、給排気の収支が釣り合う場合、次式で表す。

$$
C_T\frac{dT_i}{dt}=\sum_jG_{ij}(T_j-T_i)
+\sum_{j\to i}\rho_0c_pQ_{ji}(T_j-T_i)+H_i
$$

`C_T` は熱容量 [J/K]、`G` は熱コンダクタンス [W/K]、`Q_ji` は流入体積流量の大きさ [m³/s]、`H_i` は発熱率 [W] である。流入が正なら温度は上昇する。vtsimnx の標準顕熱移流は一定の乾き空気密度1.2 kg/m³と比熱1006 J/(kg·K)を用いる。湿り空気エンタルピーを扱う設定では式が拡張される。

室内空気は節点内で完全混合、壁体は厚さ方向の一次元伝熱を基本とする。室内温度分布、噴流、二次元熱橋等を直接解くCFDモデルではない。`v` だけでは空気熱容量は生成されず、`thermal_mass` に総熱容量を明示する。

## 2. 日射と方位

| 記号 | 物理量 | 単位 |
|---|---|---|
| GHI | 水平面全天日射照度 | W/m² |
| DNI | 法線面直達日射照度 | W/m² |
| DHI | 水平面拡散日射照度 | W/m² |

太陽高度 `h_s>0` の同一時刻では `GHI = DNI*sin(h_s) + DHI` である。観測値の時間平均・代表時刻が異なる場合には差が生じる。**DNI+DHIを水平面全天日射としない。** GHIのみからの直散分離はErbs経験式による推定であり、観測したDNI/DHIと同等の情報を持たない。

太陽・面方位角は南0°、東−90°、西+90°、北±180°。面傾斜角は水平上向き0°、鉛直90°である。気象の時刻基準、時間積算値と照度の区別、タイムゾーンをそろえる。実装の時刻処理は [日射ガイド](solar_usage.md) を参照する。

## 3. 外皮伝熱と窓日射

定常熱貫流は `H = U*A*(T_in-T_out)` で表せる。ここでは室外への損失を正とし、`H` は W、`U` は表面抵抗を含む熱貫流率 [W/(m²·K)]、`A` は m²である。非定常時は壁体の容量と初期温度が時間遅れに影響する。

ただし、現行 builder の `surfaces.u_value` は表面間の係数として扱われ、両側の表面熱伝達抵抗が別に加わる。上式の `U` と同一視しない。入力層の順序、放射と対流の区別も [表面ガイド](surface_usage.md) で確認する。

窓の日射は直達・天空拡散・地面反射に分かれる。シェード関数は幾何学的な直達遮蔽のみを扱い、拡散・反射の遮蔽は変更しない。ガラス補正と builder の配分・吸収率を併記し、日射熱取得を二重計上しない。

## 4. 換気・風圧

開口流量は風圧差、浮力による圧力差、機械送風などで定まる。代表的な風圧式は `p_w = C_p*ρ*u²/2` であり、風圧係数は形状・風向・周囲条件に依存する。`make_wind` の既定値と符号は [機能ガイド](archenv_comfort_nocturnal_wind_usage.md) の実装上の注意を参照する。

圧力 solver は未知圧力節点の**体積流量収支**を解く。湿気輸送では一定密度を掛けて質量流量へ換算する。これは温湿度依存密度による厳密な可変密度質量保存とは区別する。換気は顕熱・水蒸気・汚染物質を運ぶため、風量だけでなく流向・給気状態・生成率をそろえる必要がある。

## 5. 湿気・夜間放射・地盤

`x` は乾き空気1 kg当たりの水蒸気質量 [kg/kg']（湿度比）である。本資料ではこれを絶対湿度と呼ぶ。容積絶対湿度 [kg/m³] と区別する。相対湿度は同じ温度の飽和水蒸気圧に対する水蒸気分圧の割合 [%] であり、保存量ではない。

熱・湿気は主に後退Euler法で求解する。正の容量・受動的な伝達係数を持つ線形系での数値安定性は、任意の連成計算の収束や粗い時間刻みでの精度を保証しない。現行湿気モデルは線形容量・伝達・移流・発湿を扱い、吸着履歴や液水移動を直接解かない。

天空への長波放射により外表面が外気より低温になる場合がある。「夜間放射」という入力名でも関数は昼夜を判定しない。地盤温度は地表の相当外気温と深部固定温度を境界とする一次元熱伝導の推定であり、建物基礎との三次元連成や地下水移流は含まない。助走は初期状態の影響を減らす処理であり、収束を自動保証しない。

## 6. PMV/PPDと解釈の限界

PMV は代謝量、外部仕事、着衣量、気温、平均放射温度、気流速度、相対湿度から計算する集団平均の温冷感指標である。PPDは不満足者率の予測値で、PMV=0でも5%となる。個人の快適性や局所不快、健康影響を直接保証するものではない。

本実装には衣服表面温度の反復計算がある。未収束警告、入力条件、実装の適用範囲を確認して用いる。規格適合性の認証と、関数値が計算できることは異なる（[快適性ガイド](archenv_comfort_nocturnal_wind_usage.md)）。

## 7. 研究利用時に残す情報

- 実行コードのバージョン・commit、raw入力、builder展開後の入力。
- 境界条件、初期条件、助走期間、時間刻み、気象時刻と単位。
- 材料・漏気・空調・生活プロファイルの採用値と出典。
- 収束条件、収支残差、既知解・他ソフト・実測との比較条件。
- 時間刻み・層分割・入力不確かさに対する感度。

[検証方針](validation_strategy.md) は実装検証と物理的妥当性確認を区別している。既知解や他ソフトとの一致だけで、すべての実建物での精度が証明されたとはしない。
