# ソルバログ規約（第1段）

C++ solver（`solver.log`）のログ表記の正本です。  
ループ構造は [`simulation_loops.md`](simulation_loops.md)、Ceres と物理合否の分離は [`physics_math_notes.md`](physics_math_notes.md) を参照してください。

## 階層

- 深さは **`ScopedLogSection` / `ScopedLogIndent`**（ASCII 2 スペース）のみで表現する
- 新規に `----`・全角スペース・タブでインデントを作らない
- レガシーな先頭 `----` は `writeLog` が剥がす（既存行の移行は任意）

## 合否語彙

| 意味 | 語彙 | 例 |
|---|---|---|
| 換気の物理収支（`mass_maxAbs ≤ ventilationTolerance`） | **合格 / 未達** | `[圧力] 物理収支合格` |
| 線形ソルバ・連成反復の停止 | **収束 / 未収束** | `[熱] 熱計算(線形): 収束` |
| Ceres 最適化の相対停止 | **Ceres相対停止(CONVERGENCE)** | 物理合格と混同しない |

## 重大度

本文は日本語。プレフィックスは次に固定する。

- `[INFO]` — フォールバック移行など、失敗ではない告知
- `[WARN]` — 続行可能な異常・フォールバック・近似
- `[ERROR]` — 停止や受理不可に繋がる失敗

## ドメインタグ

主要診断行の先頭に短いタグを付ける。

| タグ | 対象 |
|---|---|
| `[圧力]` | 換気回路網の圧力求解 |
| `[熱]` | 熱回路網（DirectT など） |
| `[湿気]` | 絶対湿度ソルバ |
| `[濃度]` | 濃度更新 |
| `[空調]` | エアコン制御 |
| `[連成]` | 内側／外側連成ループの制御メッセージ |

ヘルパ: `writeDomainLog(os, "圧力", "...")` → `[圧力] ...`（[`utils.h`](../solver/utils/utils.h)）。

## ドメイン別の最小方針

- **圧力**: Ceres 停止と物理合否を分けて書く。最終受理は「物理収支合格」
- **熱**: 収支 RMSE による収束／未収束。線形代数失敗は `[ERROR]`
- **湿気**: 成功時の毎ステップログは出さない。未収束時のみ
- **濃度**: `calc_c` 有効かつ verbosity≥1 で更新完了を1行。異常時は `[ERROR]`
- **空調**: 代表行に `[空調]`。全角スペースの全面除去は第2段以降
- **連成**: セクション名（`圧力計算` / `熱計算`）は維持し、制御メッセージに `[連成]`
